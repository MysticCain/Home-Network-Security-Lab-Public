**Project title:** Home Network Security Lab | VLAN Segmentation \& Firewall Access Control

**Description:**
Designed and implemented a segmented home network using a TP-Link Omada ER605 router, ES208G managed switch, and EAP720 wireless access point. Created dedicated VLANs for trusted devices, IoT/smart-home devices, guests, and network management, then configured inter-VLAN firewall rules to reduce unnecessary access between networks. Verified DHCP addressing and connectivity using Windows networking tools and Android-based tests, investigated firewall behavior, and troubleshot 5 GHz Wi-Fi performance. Documented testing limitations and identified a remaining router-management access-control improvement for future remediation.

# Optional LinkedIn Post

I recently completed a hands-on home network security lab focused on VLAN segmentation and firewall access control.

Using TP-Link Omada equipment, I separated trusted computers, IoT/smart-home devices, guest devices, and network infrastructure into dedicated VLANs. I configured access-control rules, validated connectivity across networks, and troubleshot a Windows wireless client's 2.4 GHz versus 5 GHz connection.

One of the most valuable lessons was learning that inter-VLAN firewall rules do not necessarily restrict access to the router's own management interface. I documented that as a remaining improvement rather than treating the setup as fully secured.

This project helped me build practical skills in network security, troubleshooting, and documenting real-world security controls.
